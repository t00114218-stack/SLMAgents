Enterprise Record: Does the Hosted AWS Marketplace SKU support customer-managed

Document ID: dsid_8f0b7a8c1dbb4df0b23f6c4e61c9f1a6
System Source: confluence
Details & Summary:
Updated (2026 FAQ): Hosted uses provider-managed KMS keys by default, but customer-managed KMS (BYOK) is available for enterprise tenants in select regions as an add-on (subject to feasibility); if it's not available in the target region, Hosted remains provider-managed. Dedicated supports customer-managed keys in many configurations, and Private/VPC supports customer-managed keys and is typically recommended when BYOK is a hard requirement. (Note: an earlier Northpeak call indicated Hosted could not do BYOK and suggested Private as the path.)

- The answer must state that Hosted uses provider-managed KMS keys by default.
- The answer must state that, per updated 2026 guidance, Hosted customer-managed KMS (BYOK) is available for enterprise tenants in select regions as an add-on and is subject to feasibility/review.
- The answer must NOT claim Hosted BYOK is available in all regions or for all tenants.
- The answer must state that if Hosted BYOK is not available in the target region, the default is provider-managed keys.
- The answer must state that Private (VPC) supports customer-managed keys and is typically recommended when BYOK is a hard requirement.
- The answer must state that Dedicated has customer-managed key options for many configurations (without overstating universal support).
- The answer may mention the older meeting note that Hosted could not do BYOK, but it must clarify that this was superseded by the updated 2026 FAQ.

Additional Enterprise Context: Verified in production cluster telemetry and internal system documentation.
