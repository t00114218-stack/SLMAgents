- Each contract conformance results ledger entry must include service_a
- Each contract conformance results ledger entry must include service_a_version
- Each contract conformance results ledger entry must include service_b
- Each contract conformance results ledger entry must include service_b_version
- Each contract conformance results ledger entry must include an endpoint
- Each contract conformance results ledger entry must include dcts_version
- Each contract conformance results ledger entry must include test_case_id
- Each contract conformance results ledger entry must include a result value of pass or fail
- Each contract conformance results ledger entry must include failure_reason
