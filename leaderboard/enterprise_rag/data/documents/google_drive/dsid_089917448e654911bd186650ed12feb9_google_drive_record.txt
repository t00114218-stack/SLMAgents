Enterprise Record: What is the proposed HTTP header scheme for attributing API 

Document ID: dsid_089917448e654911bd186650ed12feb9
System Source: google_drive
Details & Summary:
The proposal is to tag template-originated API traffic with an optional header `X-Redwood-Template`, whose value is formatted as `<template_name>@<template_version>;<language>` (e.g., `rag-agent@1.1.0;python`). An additional opt-in header `X-Redwood-Template-Opt-In` is set to `true` or `false`.

- API traffic originating from quickstart templates is tagged with an optional HTTP header named X-Redwood-Template.
- The X-Redwood-Template header value is formatted as <template_name>@<template_version>;<language> (for example, rag-agent@1.1.0;python).
- An additional opt-in header named X-Redwood-Template-Opt-In is included and is set to true or false.

Additional Enterprise Context: Verified in production cluster telemetry and internal system documentation.
