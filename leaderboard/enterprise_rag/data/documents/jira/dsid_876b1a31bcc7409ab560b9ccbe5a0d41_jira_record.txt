Details & Summary:
This happens during retention compaction warmup in us-east: rollup queries for >30-day ranges sometimes hit partitions that are marked compacted but not yet backfilled/repaired, so the primary read path returns empty rollups and the UI renders them as zero or stale. At the same time the trace-anchor index is being reindexed, so the join used for trace drill-through temporarily returns no anchors ("No traces"); once backfill/reindex completes (about 10-30 minutes), the charts and trace links recover.

- The issue occurs during retention compaction warmup in us-east.
- For date ranges over 30 days, rollup queries can hit partitions marked compacted but not yet backfilled or repaired.
- When those partitions are queried, the primary read path can return empty rollups, causing the UI to briefly show zero or stale chart values.
- During the same period, the trace-anchor index is being reindexed, so the join used for trace drill-through can temporarily return no anchors and show no traces.
- Once the backfill and reindex complete, typically after about 10 to 30 minutes, the charts and trace drill-through links recover.

Additional Enterprise Context: Verified in production cluster telemetry and internal system documentation.
