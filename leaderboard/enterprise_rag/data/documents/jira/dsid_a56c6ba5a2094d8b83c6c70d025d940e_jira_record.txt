Details & Summary:
On managed iOS devices behind the Apple HTTP proxy, backgrounding can trigger a connection warm-up/path negotiation and an intermediary idle probe that coalesces a delayed FIN with a TCP socket migration. The edge then marks the SSE as a partial close and ends it before the serving runtime can flush its last buffered tokens, so the client sees a brief stall, no explicit end marker, and a truncated final JSON object.

- On managed iOS devices behind the Apple HTTP proxy, backgrounding can trigger connection warm-up or path negotiation plus an intermediary idle probe.
- The intermediary behavior can coalesce a delayed FIN with a TCP socket migration.
- The edge can treat the server-sent event stream as a partial close and terminate it.
- The stream can be terminated before the serving runtime flushes its last buffered tokens.
- As a result, the client can see a brief stall, no explicit end marker, and a truncated final JSON object.

Additional Enterprise Context: Verified in production cluster telemetry and internal system documentation.
