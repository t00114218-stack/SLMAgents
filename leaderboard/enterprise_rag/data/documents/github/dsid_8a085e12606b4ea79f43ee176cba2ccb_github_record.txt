Enterprise Record: Do I need to set enable_tool_signal for tool-signal in the R

Document ID: dsid_8a085e12606b4ea79f43ee176cba2ccb
System Source: github
Details & Summary:
No. Tool-signal is now automatically enabled when tool calls are present (model emits tool-call events or the request includes tools), and there is no per-request enable_tool_signal flag on the public OpenAI-compatible surface. Private deployments can disable it via server config: openai_compat.tool_signal_enabled=false. (Older PR notes mentioned an enable_tool_signal flag with default true for hosted; that is outdated.)
