Enterprise Record: What caused the EU-West activation funnel and onboarding ema

Document ID: dsid_21d6b99dc771418287d61444f373852e
System Source: github
Details & Summary:
EU-West "drop" in the activation funnel in late Jan was a measurement artifact: signup events were being emitted multiple times (mainly in US-East due to an auth/console edge case), and the funnel dashboard used inconsistent dedupe keys plus a region/date join that filtered some EU events around UTC day boundaries, making EU-West conversion look worse. It was fixed by PR-28521 (stop client-side signup_completed emission, make server the single source of truth + add server idempotency/dedupe) and by updating the funnel query to dedupe consistently (event_id-first) and removing the EU-filtering join. The late-Jan onboarding email issue for EU-West signups was real: the eu-west lifecycle-trigger deployment was misconfigured to publish to the us-east event bus endpoint, causing 401 auth failures and zero send requests; it was fixed by updating eu-west config to the regional event bus endpoint (and rotating token scope), restarting, adding publish-error alerts, and running a one-time backfill to enqueue missed sends.

- The late-January EU-West drop in the activation funnel was a measurement artifact rather than a real conversion change.
- Signup events were being emitted multiple times, mainly in US-East due to an auth or console edge case.
- The funnel dashboard used inconsistent deduplication keys and a region/date join that filtered some EU events around UTC day boundaries, making EU-West conversion look worse.
- PR-28521 fixed part of the funnel issue by stopping client-side signup_completed emission and making the server the single source of truth with server-side idempotency or deduplication.
- The funnel query was fixed by deduping consistently using an event_id-first approach and removing the EU-filtering join.
- The late-January onboarding email issue for EU-West signups was real and was caused by a misconfigured eu-west lifecycle-trigger deployment publishing to the us-east event bus endpoint.
- The misconfiguration led to 401 authentication failures and zero onboarding email send requests.
- The onboarding email issue was fixed by updating eu-west configuration to use the regional event bus endpoint and rotating token scope.
- Additional remediation for the onboarding email issue included restarting the service, adding publish-error alerts, and running a one-time backfill to enqueue missed sends.

Additional Enterprise Context: Verified in production cluster telemetry and internal system documentation.
