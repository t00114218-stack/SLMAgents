Details & Summary:
They added dynamic scratch reuse: a runtime scratch manager/allocator that lifetime-tags short-lived temporary buffers and reuses them across operators within the same execution frame, so attention/rotary/layernorm no longer allocate fresh per-op scratch and the transient device-memory spikes are reduced.

- The runtime introduced dynamic scratch reuse to reduce worst-case temporary device-memory spikes when short and long requests are interleaved.
- Dynamic scratch reuse is implemented via a runtime scratch manager or allocator that lifetime-tags short-lived temporary buffers.
- The scratch manager reuses temporary buffers across operators within the same execution frame instead of allocating fresh per-op scratch buffers.
- With dynamic scratch reuse, attention-heavy operators such as attention, rotary, and layernorm no longer allocate new per-op scratch buffers, reducing transient device-memory spikes.
