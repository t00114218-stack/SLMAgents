The compatibility layer validates forced tool/function calls against the registered schemas and fails closed if the schema is invalid. On validation failure, it returns an HTTP 422 with a structured error payload (and emits a telemetry event).

- The v1 chat compatibility layer validates forced tool or function calls against the registered schemas.
- If a tool or function schema is invalid, the compatibility layer fails closed.
- When validation fails, the compatibility layer returns HTTP status 422.
