Details & Summary:
The bandwidth-aware fanout planner is controlled by the config flag "runtime.bandwidth_fanout.enabled". The release notes also call out KV-shard coalescing, a small stride-optimized memcpy kernel, and stream mapping as new components that help reduce communication/computation stalls.
