Details & Summary:
The PR reduced long-context OOMs by introducing an opt-in activation checkpointing mode (trading some recompute for lower activation memory) and refactoring CUDA scratch buffers so temporary GPU allocations are reused across micro-batches in the continuous-batching loop. On an A100 40GB at seq≈4096, it cut peak GPU memory by about 36% (with expected savings up to ~40% on long-sequence workloads).

- The change added an opt-in activation checkpointing or recompute mode that trades extra recomputation for lower activation memory use.
