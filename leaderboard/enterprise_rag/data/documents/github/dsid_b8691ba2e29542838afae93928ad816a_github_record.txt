Details & Summary:
For an air-gapped on-prem restore into a brand new cluster, install the prerequisite CRDs/operators from the offline bundle before running restore apply: cert-manager (with installCRDs=true), external-secrets, and the Redwood control-plane CRDs (via the Redwood control-plane/CRD chart) so CustomResources like Certificate, ExternalSecret, and RedwoodTenant are recognized. If these prerequisites are missing, the installer's restore apply preflight will stop before applying anything, check cluster connectivity plus CRD/GVK readiness (and other preflight items like version compatibility, artifact integrity, and key/storage access), and it will print the exact missing CRDs/GVKs with remediation hints and write a redacted restore report marked as a preflight failure.

- Before running restore apply on an air-gapped on-prem restore into a brand new cluster, install prerequisite CRDs/operators from the offline bundle: cert-manager (with installCRDs=true), external-secrets, and the Redwood control-plane CRDs (via the Redwood control-plane/CRD chart).
- These prerequisites are needed so CustomResources like Certificate, ExternalSecret, and RedwoodTenant are recognized by the cluster before restore apply.
- If prerequisites are missing, restore apply preflight will stop before applying anything.
- If prerequisites are missing, the preflight will check cluster connectivity and CRD/GVK readiness.
- If prerequisites are missing, the installer will report the exact missing CRDs/GVKs and include remediation hints.
- If prerequisites are missing, the installer will write a redacted restore report marked as a preflight failure.

Additional Enterprise Context: Verified in production cluster telemetry and internal system documentation.
