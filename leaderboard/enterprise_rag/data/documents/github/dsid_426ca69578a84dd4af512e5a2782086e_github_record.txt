The PR introduces three precision modes: **strict** (fp32 only), **balanced** (fp16 allowed but only under strict runtime validators), and **aggressive** (fp16/int8 allowed once the deployment has warmed and validators have a recent success window).

- Three runtime precision modes are introduced: strict, balanced, and aggressive.
- Strict mode allows fp32 only.
- Balanced mode allows fp16 but only under strict runtime validators.
- Aggressive mode allows fp16 or int8 once the deployment has warmed and validators have a recent success window.
