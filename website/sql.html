    📊 Natural Language to SQL

    SLM Text-to-SQL

    Translates natural language questions into valid SQL queries against custom database schemas offline.

    Overview Installation Configuration Env Variables Performance

    Overview

    Translates natural language questions into valid SQL queries against custom database schemas offline.

    🚀 Core Capabilities

    • Offline schema parsing and SQL translation
    • Dialect support: PostgreSQL, SQLite, MySQL
    • Guarantees valid syntax without leaking data to external servers

    Installation

    Install the local CPU-optimized package using pip:

    Terminal
    # Install local CPU-optimized package
pip install slm-text-to-sql

    Configuration API

    Constructor Parameters

    Instantiate SLMTextToSQL with performance and tool options:

    ParameterType / DefaultDescription
    model_pathstr | NonePath to local ONNX Text-to-SQL model. Default: `None`.
    temperaturefloat | 0.0Sampling temperature controlling SQL generation randomness. Default: `0.0`.
    top_pfloat | 0.9Nucleus sampling cutoff threshold. Default: `0.9`.
    max_tokensint | 256Maximum token generation length limit per query. Default: `256`.
    cache_dirstr | NoneDirectory for storing cached model weights. Default: `None`.
    n_threadsint | 4CPU threads for inference execution. Default: `4`.

    Methods

    Method SignatureReturn TypeDescription
    generate_sql(schema, query, ...)strConverts natural language questions and schemas into executable SQL statements.

    Execution Method Parameters

    Complete list of execution parameters accepted by the main method:

    ParameterType / DefaultDescription
    schemastrDatabase DDL table schema definitions string.
    querystrNatural language query description.
    system_promptstr | NoneSQL generation guidelines or dialect constraints. Default: `None`.
    user_inputstr | NoneAdditional column filters or custom constraints. Default: `None`.
    temperaturefloat | 0.0Sampling temperature parameter. Default: `0.0`.
    top_pfloat | 0.9Nucleus sampling probability cutoff threshold. Default: `0.9`.
    max_tokensint | 256Maximum generation token limit. Default: `256`.

    Quick Start

    from slm_text_to_sql import SLMTextToSQL

sql_agent = SLMTextToSQL(temperature=0.0, top_p=0.9, max_tokens=256)
query = sql_agent.generate_sql(
    schema="CREATE TABLE sales (id INT, amount DECIMAL, region TEXT);",
    query="What is total sales in West?",
    system_prompt="Dialect: PostgreSQL",
    user_input="Add WHERE amount > 0 condition",
    temperature=0.0,
    top_p=0.9,
    max_tokens=256
)
print(query)

    Environment Variables

    Configure agent parameters globally using environment values:

    Environment VariableDefaultPurpose
    SLM_SQL_N_THREADS4Sets CPU inference execution threads.
    SLM_SQL_CACHE_DIR~/.cache/slm-text-to-sql/Default directory to store downloaded ONNX weights.

    CPU Performance Tuning

    To run the SLMTextToSQL engine efficiently on CPU under 1.5 GB memory footprint:

    • Match Threads to Core Count: Set n_threads or SLM_SQL_N_THREADS to match physical CPU core count.
    • Sequential Processing: Avoid concurrent processing when batch files are large.
    • Garbage Collection: Clear variables and run gc.collect() to release model RAM blocks after execution.
