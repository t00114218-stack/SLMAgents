SLM Orchestrator: Offline LLM Routing on CPU

A lightweight, local semantic router powered by a 1.5B ONNX Small Language Model. Automatically routes user queries to specialized sub-agents with robust JSON constraints.

  • Structured Routing Output: Constrains response structure to exact agent schemas.
  • Transparent Download: Automatically downloads, caches, and runs models on first execution.
  • Highly Configurable: Set custom thread counts and context limits optimized for CPU.
GitHub Repo
Orchestrator Setup
# Install via pip
pip install slm-orchestrator

# Note: Requires onnxruntime-genai and huggingface-hub
# Installs pre-compiled wheel files for CPU execution
from slm_orchestrator import SLMOrchestrator

# Initialize router (runs locally on CPU via ONNX)
orchestrator = SLMOrchestrator()

# Define agents to route to
agents = [
    {"name": "Billing", "description": "Payments"},
    {"name": "Support", "description": "Tech bugs"}
]

# Classify with JSON post-processing constraint
selected = orchestrator.route(
    agents=agents,
    question="Invoices and payment help"
)
print(selected) # Output: Billing

SLM RAG: Local Retrieval-Augmented Generation

A local Retrieval-Augmented Generation library built around a 1.5B model. Provides privacy-first context querying using highly optimized ONNX Runtime pipelines.

  • High RAM Efficiency: Consumes only 1.0 GB to 1.5 GB RAM during active CPU inference.
  • Strict Guidelines: Integrates system-level instruction filters directly into Qwen templates.
  • Local Execution: Fully self-contained pipeline utilizing quantized Qwen ONNX weights.
GitHub Repo
RAG Setup
# Install via pip
pip install slm-rag

# Note: Requires onnxruntime-genai and huggingface-hub
# Shares the same cached model to save local disk storage
from slm_rag import SLMRag

# Init engine (downloads/caches 1.5B Qwen ONNX)
rag = SLMRag()

# Define context chunks
chunks = [
    "NebulaCorp was founded in 2024 by Dr. Helena.",
    "Their flagship product is AegisShield."
]

# Run local query with pirate guidelines
answer = rag.answer(
    chunks=chunks,
    question="What is their flagship product?",
    instruction="Answer like a 17th-century pirate."
)
print(answer)
# Output: Ahoy! AegisShield be their flagship!

SLM Summarizer: Text Summarization without GPU

A local text summarization agent powered by a 1.5B ONNX Small Language Model. Automatically condenses documents using single-pass or Map-Reduce methods on standard CPUs.

  • High RAM Efficiency: Consumes only 1.0 GB to 1.5 GB RAM during active CPU summarization.
  • Format Constraints: Choose between bullet points, paragraphs, or concise TL;DR outputs.
  • Map-Reduce Support: Chunk and summarize large local text files without exceeding memory limits.
GitHub Repo
Summarizer Setup
# Install via pip
pip install slm-summarizer

# Note: Requires onnxruntime-genai and huggingface-hub
# Shares the same cached model to save local disk storage
from slm_summarizer import SLMSummarizer

# Init engine (downloads/caches 1.5B Qwen ONNX)
summarizer = SLMSummarizer()

text = "SpaceX successfully launched its Falcon 9 rocket on Friday..."

# Summarize locally with format constraints
summary = summarizer.summarize(
    text=text,
    format="bullet_points",
    instruction="Focus on launch metrics."
)
print(summary)

SLM Text-to-SQL: Database Queries using Local AI

A CPU-optimized Text-to-SQL translation agent powered by a 1.5B ONNX Small Language Model. Includes native QLoRA adapters training workflows for GPU/TPU.

  • Database-to-SQL Mapping: Translates natural queries into precise SQL statements based on table schemas.
  • Hugging Face Integration: Uses Qwen chat templates directly for prompt tokenization and schema mapping.
  • Built-in QLoRA Trainer: Complete training, validation, and adapter-merging scripts for fine-tuning.
GitHub Repo
Text-to-SQL Setup
# Install via pip
pip install slm-text-to-sql

# Note: Requires onnxruntime-genai and huggingface-hub
# Shares the same cached model to save local disk storage
from slm_text_to_sql import SLMTextToSQL

# Init engine (downloads/caches 1.5B Qwen ONNX)
agent = SLMTextToSQL()

schema = "CREATE TABLE employees (id INT, salary INT);"

# Generate SQL locally on CPU
query = agent.generate_sql(
    schema=schema,
    question="Average salary?"
)
print(query)
# Output: SELECT AVG(salary) FROM employees;
