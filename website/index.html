SLM Orchestrator

A lightweight, local semantic router powered by a 1B Small Language Model. Automatically routes user queries to specialized sub-agents with strict output constraints.

  • GBNF Grammar Routing: Constrains outputs on-the-fly to strict agent names.
  • Transparent Download: Automatically downloads, caches and runs models on first execution.
  • Highly Configurable: Set custom thread counts and context limits optimized for CPU.
GitHub Repo
Orchestrator Setup
# Install via pip
pip install slm-orchestrator

# Note: Requires llama-cpp-python and huggingface_hub
# Make sure your compiler is configured for CPU threads
from slm_orchestrator import SLMOrchestrator

# Initialize router (runs locally on CPU)
orchestrator = SLMOrchestrator()

# Define agents to route to
agents = [
    {"name": "Billing", "description": "Payments"},
    {"name": "Support", "description": "Tech bugs"}
]

# Constrained output classification
selected = orchestrator.route(
    agents=agents,
    question="Invoices and payment help"
)
print(selected) # Output: Billing

SLM RAG

A local Retrieval-Augmented Generation library built around a 1.5B model. Provides privacy-first context querying with a footprint under 1.5 GB of RAM.

  • High RAM Efficiency: Consumes only 1.0 GB to 1.5 GB RAM on local laptops.
  • Strict Guidelines: Integrates custom instructions directly into system templates.
  • Local Execution: Fully self-contained pipeline using quantized Qwen-based architectures.
GitHub Repo
RAG Setup
# Install via pip
pip install slm-rag

# Note: Requires llama-cpp-python and huggingface_hub
# Make sure your compiler is configured for CPU threads
from slm_rag import SLMRag

# Init engine (downloads/caches 1.5B GGUF)
rag = SLMRag()

# Define context chunks
chunks = [
    "NebulaCorp was founded in 2024 by Dr. Helena.",
    "Their flagship product is AegisShield."
]

# Run local query with persona constraints
answer = rag.answer(
    chunks=chunks,
    question="What is their flagship product?",
    instruction="Answer like a 17th-century pirate."
)
print(answer)
# Output: Ahoy! AegisShield be their flagship!
