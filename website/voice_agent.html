    SLM Voice Agent

    Fast offline conversational companion combining Whisper speech-to-text, 1.5B chat, and lightweight text-to-speech pipelines on CPU.

    Overview Installation Configuration Env Variables Performance

    Overview

    Fast offline conversational companion combining Whisper speech-to-text, 1.5B chat, and lightweight text-to-speech pipelines on CPU.

    🚀 Core Capabilities

    • Offline audio-to-text speech transcription
    • Low-latency response generation using quantized ONNX
    • Text-to-speech synthesis utilizing local CPU synthesizer models
    • Hands-free voice trigger support

    Installation

    Install the local CPU-optimized package using pip:

    Terminal
    # Install local CPU-optimized package
pip install slm-voice

    Configuration API

    Constructor Parameters

    Instantiate SLMVoiceAgent with performance options:

    ParameterType / DefaultDescription
    model_pathstr | NoneExplicit path to ONNX model weights. If omitted, downloads standard checkpoints.
    cache_dirstr | NoneDirectory to store model weights offline. Defaults to ~/.cache/slm-voice/. Also settable via SLM_VOICE_AGENT_CACHE_DIR.
    n_threadsint | 4CPU thread count for ONNX inference. Optimize for CPU core count. Also settable via SLM_VOICE_AGENT_N_THREADS.

    Methods

    Method SignatureReturn TypeDescription
    process_speech_text(speech_transcript, language='english', system_prompt=None, user_input=None)dictProcesses text inputs to simulate offline voice recognition loops, synthesizing spoken agent responses.

    Method Parameters (Execution Customization)

    All main execution methods accept optional system routing parameters:

    ParameterType / DefaultDescription
    system_promptstr | NoneOptional custom system prompt instruction to override the default system template response parameters.
    user_inputstr | NoneOptional additional user-supplied target text variables or contextual keys.

    Quick Start

    from slm_voice import SLMVoiceAgent

voice = SLMVoiceAgent()
voice.process_speech_text(
    "Hello local CPU assistant",
    language="Hindi",
    system_prompt="Respond in a polite voice assistant style",
    user_input="Prefer vector search results"
)

    Environment Variables

    Configure agent parameters globally using environment values:

    Environment VariableDefaultPurpose
    SLM_VOICE_AGENT_N_THREADS4Sets CPU inference execution threads.
    SLM_VOICE_AGENT_CACHE_DIR~/.cache/slm-voice/Default directory to store downloaded ONNX weights.

    CPU Performance Tuning

    To run the SLMVoiceAgent engine efficiently on CPU under 1.5 GB memory footprint:

    • Match Threads to Core Count: Set n_threads or SLM_VOICE_AGENT_N_THREADS to match the physical CPU core count.
    • Sequential Processing: Avoid concurrent processing when batch files are large.
    • Garbage Collection: Clear variables and run gc.collect() to release model RAM blocks after execution.
