    SLM Voice Agent

    Fast offline conversational companion combining Whisper speech-to-text, 1.5B chat, and lightweight text-to-speech pipelines on CPU.

    Overview Installation Configuration Env Variables Performance

    Overview

    Fast offline conversational companion combining Whisper speech-to-text, 1.5B chat, and lightweight text-to-speech pipelines on CPU.

    🚀 Core Capabilities

    • Audio-only (.wav, .mp3, .m4a) and text transcript query processing
    • Real-time barge-in interruption support allowing users to interrupt speech playback
    • Configurable LLM inference parameters: temperature, top_p, and max_tokens
    • Configurable sub-agent tool calls and multilingual translation routing

    Installation

    Install the local CPU-optimized package using pip:

    Terminal
    # Install local CPU-optimized package
pip install slm-voice

    Configuration API

    Constructor Parameters

    Instantiate SLMVoiceAgent with performance and tool options:

    ParameterType / DefaultDescription
    model_pathstr | NoneExplicit path to ONNX model weights directory. Default: `None`.
    toolsdict | NoneDictionary of registered tool callbacks: `{"RAG": rag_fn, "Math": math_fn}`. Default: `None`.
    system_promptstr | NoneCustom system instructions defining tool selection rules. Default: `None`.
    barge_inbool | TrueEnables real-time speech interruption of TTS audio playback. Default: `True`.
    barge_in_sensitivityfloat | 0.5Sensitivity threshold for audio interruption detection (0.0 to 1.0). Default: `0.5`.
    temperaturefloat | 0.7Sampling temperature controlling LLM output randomness. Default: `0.7`.
    top_pfloat | 0.9Nucleus sampling probability cutoff threshold. Default: `0.9`.
    max_tokensint | 256Maximum token generation output length limit per request. Default: `256`.
    cache_dirstr | NoneDirectory to store model weights. Defaults to `~/.cache/slm-voice/`. Default: `None`.
    n_threadsint | 4CPU thread count for ONNX inference execution. Default: `4`.

    Methods

    Method SignatureReturn TypeDescription
    process_speech_text(speech_transcript=None, ...)dictProcesses audio file or transcript inputs, executes tool calls if triggered, and synthesizes spoken outputs with barge-in support.
    process_audio(audio_file, ...)dictConvenience execution method for audio-only file inputs (.wav, .mp3, .m4a).
    register_tool(name, callable_fn)NoneRegisters a custom agent callback or Python function mapping dynamically.

    Complete list of execution parameters accepted by the main method:

    ParameterType / DefaultDescription

    Quick Start

    from slm_voice import SLMVoiceAgent
from slm_rag import SLMRag

# Initialize sub-agent tool
rag = SLMRag()

# Initialize Voice Agent with barge-in & LLM parameters
voice = SLMVoiceAgent(
    tools={"RAG": lambda q, **kw: rag.answer(chunks=None, question=q)},
    barge_in=True,
    barge_in_sensitivity=0.5,
    temperature=0.7,
    top_p=0.9,
    max_tokens=256
)

# Audio file input execution with barge-in support
res1 = voice.process_audio(
    audio_file="user_query.wav",
    language="Hindi",
    system_prompt="Strict formal voice responses",
    user_input="Focus on financial data",
    barge_in=True,
    temperature=0.7
)

# Text transcript input execution
res2 = voice.process_speech_text(
    speech_transcript="RAG search Q3 revenue",
    language="Tamil",
    system_prompt="Summarize answers concisely",
    user_input="Exclude archived files",
    temperature=0.7,
    top_p=0.9,
    max_tokens=256
)
print(res2)

    SLM_VOICE_AGENT_CACHE_DIR~/.cache/slm-voice/Default directory to store downloaded ONNX weights.

    CPU Performance Tuning

    To run the SLMVoiceAgent engine efficiently on CPU under 1.5 GB memory footprint:

    • Match Threads to Core Count: Set n_threads or SLM_VOICE_AGENT_N_THREADS to match physical CPU core count.
    • Sequential Processing: Avoid concurrent processing when batch files are large.
    • Garbage Collection: Clear variables and run gc.collect() to release model RAM blocks after execution.
