      SLM Web Agent

      Automate multi-step browser tasks offline. Plans actions, selects locators, and navigates forms using Playwright and Phi-3.5.

      Overview

      The SLM Web Agent uses Microsoft's MIT-licensed Phi-3.5-mini-instruct as a ReAct loop controller. It scrapes DOM nodes dynamically and translates raw visual structures into precise locator calls to execute headless browser steps via Playwright.

      API Reference

      `SLMWebAgent` Initialization

      from slm_web_agent.web_agent import SLMWebAgent

agent = SLMWebAgent()
      ParameterTypeDescription
      model_pathstrLocal directory containing pre-downloaded Phi-3.5 weights. Defaults to "../../models/phi-3.5-mini-instruct-onnx".

      `browse` Method

      result = agent.browse(goal="Confirm transaction", start_url="https://bank.com")
