    SLM RAG

    Answer questions from your own documents locally, privately, with zero API costs. Supports custom tools and vector database retrieval.

    Overview

    Answer questions from your own documents locally, privately, with zero API costs. Supports custom tools and vector database retrieval.

    🚀 Core Capabilities

    • Offline vector search retrieval using quantized ONNX models
    • Context-constrained answer generation eliminating hallucinations
    • Strict instruction adherence for custom schema formats
    • Low RAM footprint optimized for desktop CPUs

    Installation

    Install the local CPU-optimized package using pip:

    Terminal
    # Install local CPU-optimized package
pip install slm-rag

    Configuration API

    Constructor Parameters

    Instantiate SLMRag with performance and tool options:

    ParameterType / DefaultDescription
    model_pathstr | NonePath to local ONNX model directory. Default: `None`.
    temperaturefloat | 0.0Sampling temperature for RAG answer generation. Default: `0.0`.
    top_pfloat | 0.9Nucleus sampling probability cutoff. Default: `0.9`.
    max_tokensint | 256Maximum output token generation limit per answer. Default: `256`.
    cache_dirstr | NoneDirectory to cache model weights offline (`~/.cache/slm-rag/`). Default: `None`.
    n_ctxint | 8192Maximum context window token length. Default: `8192`.
    n_threadsint | 4CPU threads allocated for ONNX Runtime GenAI. Default: `4`.

    Methods

    Method SignatureReturn TypeDescription
    answer(chunks, question, instruction=None, system_prompt=None, user_input=None, temperature=0.0, top_p=0.9, max_tokens=256)str | generatorSynthesizes precise responses from retrieved document text chunks.

    Execution Method Parameters

    Complete list of execution parameters accepted by the main method:

    ParameterType / DefaultDescription
    questionstrUser query string to be answered from retrieved context.
    chunkslist[str] | NoneList of retrieved text document chunks. Default: `None`.
    instructionstr | NoneFormatting instruction rule guiding output synthesis. Default: `None`.
    system_promptstr | NoneOverriding system prompt instructing LLM behavior. Default: `None`.
    user_inputstr | NoneAdditional contextual search filters or parameter values. Default: `None`.
    temperaturefloat | 0.0Sampling temperature parameter. Default: `0.0`.
    top_pfloat | 0.9Nucleus sampling cutoff threshold. Default: `0.9`.
    max_tokensint | 256Maximum generation token limit. Default: `256`.

    Quick Start

    from slm_rag import SLMRag

rag = SLMRag(temperature=0.0, top_p=0.9, max_tokens=256)
result = rag.answer(
    chunks=["Invoice #1024 total is $450.00.", "DueDate: 2026-09-01"],
    question="What is the invoice total?",
    instruction="Extract dollar amount only",
    system_prompt="Strict zero-hallucination mode",
    user_input="Currency: USD",
    temperature=0.0,
    top_p=0.9,
    max_tokens=256
)
print(result)

    Configure agent parameters globally using environment values:

    Environment VariableDefaultPurpose
    SLM_RAG_N_THREADS4Sets CPU inference execution threads.
    SLM_RAG_CACHE_DIR~/.cache/slm-rag/Default directory to store downloaded ONNX weights.

    CPU Performance Tuning

    To run the SLMRag engine efficiently on CPU under 1.5 GB memory footprint:

    • Match Threads to Core Count: Set n_threads or SLM_RAG_N_THREADS to match physical CPU core count.
    • Sequential Processing: Avoid concurrent processing when batch files are large.
    • Garbage Collection: Clear variables and run gc.collect() to release model RAM blocks after execution.
